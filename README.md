# Student Management System 🎓

A simple Python command-line application for managing student records using a JSON file for data storage.

## Features

* Add students
* View student records
* Update student information
* Delete students
* Prevents duplicate Student IDs
* Saves data permanently in `students.json`

## How to Run

Make sure Python 3 is installed, then run:

```bash
python task7.py
```

The program will automatically create and use `students.json` to store student records.

## Example

```text
===== Student Management System =====
1. Add Student
2. View Students
3. Update Student
4. Delete Student
5. Exit

Enter your choice: 1
Enter Student ID: 101
Enter Name: Rahul
Enter Age: 20
Enter Course: Python
Student added successfully!
```

## Requirements

* Python 3.x
* No external libraries required

## Data Storage

Student information is stored locally in:

```text
students.json
```
